# SwitchPilot documentation

This directory is the documentation map for SwitchPilot. English is the
canonical language for design, engineering and release documentation. The four
localized README files are entry points; they link back to these English docs.

## Current product docs

| Document | Purpose |
|---|---|
| [CORE.md](CORE.md) | Product principles, scope and admission rules |
| [PRD.md](PRD.md) | Product requirements for the current baseline |
| [DESIGN.md](DESIGN.md) | UI/UX, copy, localization and accessibility design |
| [TECH.md](TECH.md) | Technical design and implementation constraints |
| [TESTPLAN.md](TESTPLAN.md) | Automated and manual acceptance plan |
| [EXPANSION.md](EXPANSION.md) | Candidate evaluation and future work |

## Research and history

[RESEARCH.md](RESEARCH.md) explains how the project evolved and points to the
archived experiments. Historical material under `artifacts/`, `evidence/` and
`tooling/` is kept for traceability; it is not current product guidance.
