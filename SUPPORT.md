# Support

- Read the [README](README.md) and [docs/en/CORE.md](docs/en/CORE.md) first.
- For usage questions and general discussion, open a GitHub issue with the
  appropriate template.
- For reproducible bugs, include macOS version, app version, build method
  (ad-hoc or developer identity), steps, expected/actual behavior, and whether
  the relevant permissions were granted.
- Do not paste TCC databases, Keychain data, certificates, personal paths or
  unrelated logs.
- For security issues, use [SECURITY.md](SECURITY.md), not a public issue.

This is a personal-use project; support is best-effort and no response time is
guaranteed.
