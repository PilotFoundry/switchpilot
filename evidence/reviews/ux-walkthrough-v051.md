## 结论

- 定位一致：输出音量已移除、低电量不做，面板/设置无任何回收入口；**不建议加回**。麦克风静音与屏幕清洁均未新增 TCC，符合 CORE 准入。
- **不必**把卡片栈重构成 One Switch 式行列表：当前 8 个控制项、保活需要时长分段与进度、权限需要解释，卡片分组（主操作→外观→输入→动作→权限）比扁平行更能表达层级；行列表只在控制项显著增多时才值得。需借参考的是**密度**：当前面板内容约 900pt 高（截图 760×1800@2x），过高。
- 麦克风卡内状态/文案/不支持设备降级基本达标；**但面板关闭后没有任何持续指示**，直接违反 CORE §3.6"麦克风静音…不能静默" → P0。
- 屏幕清洁的遮罩说明、鼠标退出、无倒计时符合用户要求；缺 Accessibility 时的降级只有小字状态且无行内入口，且"鼠标失效时无退出路径"未设计 → P1。
- 设置 IA 基本符合 CORE（权限→快捷键→登录→关于）；无需新增设置页功能；快捷键文案与 CORE"不做自定义录制器"冲突，需改口。

## 已通过 / 不重做

- M1 深色、M2 屏保、M3 锁屏、M10 关闭显示器、M12 麦克风（真实静音）、M13 清洁步骤 1–3 已由用户现场通过；首启/权限三态、右键菜单、单实例、撤销折叠、快捷键默认关闭、状态行拆分、浅/深对比均已达标。
- 输出音量移除、低电量不做是 CORE 明确取舍；本次走查不建议新增任何被排除项。

## 开项（按优先级）

- **P0-1 麦克风静音缺少持续可见状态（CORE §3.6 违反）**
  - 证据：静音态只在面板麦克风卡内显示"麦克风已静音"（PanelView 麦克风卡）；关闭 popover 后状态项仍为静态图标、tooltip 仍为"SwitchPilot"，右键菜单无麦克风项（AppDelegate 无 mic 相关）。
  - 建议：静音时状态项图标加 `mic.slash` 角标/替换，tooltip 改"SwitchPilot · 麦克风已静音"；右键菜单加"取消麦克风静音"（含状态勾选）；恢复后复原。无需新增权限。
  - 验收：静音→关闭面板→状态项/tooltip/VO 均可感知；右键可取消；重启/设备切换后状态仍正确。
- **P1-1 面板过高，小屏可能裁掉底部**
  - 证据：PanelView 无 ScrollView；内容约 900pt；AppDelegate `resizePopover` 仅把 popover 高度钳到 `visibleFrame-120`（约 755–830pt），超出部分被裁剪——1440×900/大字号下可能看不到底部权限卡与 footer（设置/退出）。
  - 建议：优先压缩而非重构——删除 4 行动作状态（改 tile 内联/单条最近结果），清洁入口并入 2×2 tile 网格，权限卡在缺失时置顶或压成一行；仍超阈值时加 ScrollView。验收：1440×900、1280×800、大字号下 footer/权限/清洁全部可达。
- **P1-2 清洁无权限降级不完整（M13-4 待补）**
  - 证据：缺 Accessibility 时 `startScreenCleaning` 只把"需要辅助功能授权才能锁定键盘输入"写进第 4 行状态并自动弹系统提示，清洁行内无错误/入口；用户可能不知道点哪里。
  - 建议：清洁行内 inline error + [打开辅助功能设置]；说明该功能复用现有权限、不新增 TCC。验收：撤销 AX→点清洁→无遮罩、行内给原因与入口。
- **P1-3 清洁模式无鼠标失效恢复路径**
  - 证据：清洁期间键盘事件被吞（CGEvent tap），退出仅靠遮罩上的"退出清洁模式"按钮（CleaningExitControl）；鼠标断开/失灵时键盘也无法用，只能强退进程。CORE 原则 7（安全可恢复）要求提供退出路径。
  - 建议：设计并验证一条 recovery（如隐藏安全组合/检测连续无鼠标事件后显示提示/可控超时自退），普通 UI 不显示倒计时；文档写明并按 CORE 标注"自动退出仅测试". 验收：断鼠标或屏蔽指针后仍可退出（方案二选一需用户确认）。
- **P1-4 清洁无障碍提示过时**
  - 证据：清洁按钮 `accessibilityHint("锁定键盘输入，屏幕上点击按钮或等待计时结束退出")`，但普通模式无计时/不自动退出（overlay 文案正确）。
  - 建议：改为"锁定键盘输入，移动鼠标点击退出清洁模式"。验收：VO 读数与遮罩文案一致。
- **P2-1 权限卡位置偏远**：全局"需要授权"卡在面板最底部，深色模式在顶部、锁屏在中间；缺权限时 CTA 距动作远。建议缺失态置顶，或恢复 v0.3.8 的行内 CTA（与 P1-1 压缩一起做）。验收：缺权限首屏无需滚动即可看到申请入口。
- **P2-2 麦克风降级与刷新**：不支持 mute 的设备目前只显示原因，无下一步；补"可在系统声音/设备上调整"更完整。默认输入设备切换后面板只在打开时刷新，建议监听设备变化或面板显示时刷新。验收：切换 AirPods/内置麦后状态与设备名更新。
- **P2-3 关闭显示器副标题"休眠 · 鼠标唤醒"**过度承诺唤醒方式（取决于系统密码/设置）；改"显示器休眠；唤醒取决于系统设置"。
- **P2-4 快捷键文案**：设置写"后续再评估自定义录制"，与 CORE §5"不做自定义快捷键录制器"冲突；改"固定组合，不提供自定义录制；实验项默认关闭"。
- **P2-5 清洁入口位置**：宽行按钮位于 4 行状态之后，与上方 3 个磁贴不一致；建议并入 tile 网格或独立"维护"分区，减少视线跳转。
- **P2-6 设置撤销 disclosure**：仍是自绘 chevron 按钮（非原生 DisclosureGroup），chevron 可能被 VO 单独读到；上次建议延后，可顺手 `.accessibilityHidden(true)`。

## 验收点

1. 静音→关面板：状态项图标/tooltip/右键菜单可感知并可取消；恢复后复原；VO 可读。
2. 小屏/大字号：1440×900、1280×800 下 footer（设置/退出）、权限卡、清洁入口全部可点，无裁剪。
3. 清洁无权限：无遮罩、行内原因 + 打开辅助功能设置；不弹额外 TCC（复用 AX）。
4. 清洁恢复：按最终 recovery 方案断鼠标测试可退出；普通模式无倒计时/自动退出文案。
5. 缺权限首屏：申请入口无需滚动即可见；深色/锁屏缺项行为不回归。
6. 回归：One Switch 参考仅作密度参照，不引入列表重构；M1–M3/M10/M12 已通过路径不受影响。
