03 / macOS 27 风格依据

macOS 27（Golden Gate）延续并收敛了 Liquid Glass：减少装饰性菜单图标、降低玻璃分层强度、统一圆角与更简化的视觉层级。对菜单栏小面板的落点是：少即是多——只保留有功能意义的图标，用系统材质/语义色/清晰排版建立层级，而不是堆装饰。

依据对本设计的影响
macOS 27 移除大量菜单项图标，HIG 建议图标“sparingly and with purpose”面板里图标只用于快速动作与状态提示，不给每个标签配装饰图标
降低 Liquid Glass 强度、统一圆角/简化视觉面板保持系统 popover 材质；内部只用低对比卡片底色与分隔线，不做多层毛玻璃
系统语义色与 SF Symbols成功/进行中/失败用系统绿/橙/红；动作图标用 SF Symbols
菜单栏 extras 的紧凑与低干扰宽 360，单列分区；默认不弹窗；只有破坏性动作才确认

外部参考：MacRumors：macOS 27 缩减菜单图标 · The Verge：Apple 收敛 Liquid Glass · Apple HIG：Menus · Apple HIG。外部文章为二手信息，实施以本机 macOS 27 实际渲染与官方 HIG 为准。

04 / 面板重设计：从“开关列表”到“状态 + 动作”

旧版（v0.1）问题

  • 所有功能同权重：保活、深色、两个动作混在一起，缺少优先级。
  • 权限状态只靠一行小字，用户不知道下一步该做什么。
  • 深色/锁屏缺权限时弹窗解释，打断且不便于回看。
  • 没有首次使用说明；不知道屏保/锁屏会影响屏幕。
  • 进度只有文字，缺少可感知的剩余时间。

新版（v0.2）结构

  • Header：产品身份 + 状态胶囊（保护中/空闲）。
  • 首次引导卡：三条规则 + “知道了”，写入 UserDefaults 后不再出现。
  • 保活区：主开关 + 时长 + 进度条 + 剩余时间 + 边界说明。
  • 外观区：深色开关 + 当前外观 + 权限状态 + 行内授权按钮。
  • 快速动作：两个动作磁贴；锁屏缺权限时磁贴带“需授权”，行内给出授权路径。
  • Footer：权限摘要 + 使用说明入口 + 退出。

设计 token

项目值
宽度 / 内边距360 pt / 16 pt；区块间距 14 pt；卡片圆角 10–12 pt（continuous）
字号标题 15 semibold；行标题 14 medium；正文 13；说明 12；辅助 11
颜色系统语义色：绿=保护中、橙=需授权、红=被拒绝/失败；卡片底色用 primary opacity 0.05，适配深浅外观
图标仅功能图标：动作磁贴、状态点、信息；无装饰性 icon wall
交互开关即时生效；屏保/锁屏确认后执行；权限只由用户点击请求，不在启动时弹窗
无障碍标准 Toggle/Button/Picker；accessibilityLabel/Value；状态不只靠颜色；键盘焦点可见

预览说明

  • 权限设为“已授权”后，深色开关才会真正在预览里切换；待授权/被拒绝时点开关会回弹并显示原因。

06 / 状态与上手路径

用户第一次打开界面反馈用户下一步
看到引导卡三条规则解释四个控件与权限点“知道了”开始使用；说明入口保留在 footer
点“保持亮屏”开关亮、状态胶囊“保护中”、进度条与剩余时间可选时长；关闭/到时自动释放
点“深色模式”未授权：开关回弹、出现“需要授权”与请求按钮点“请求授权…” → 系统提示 → 允许后再切换
点“启动屏保/锁定屏幕”确认框说明影响；锁屏缺权限时只显示授权引导确认/授权后执行；读不到状态时显示“未确认”
权限被拒绝/撤销对应行显示红色错误码与设置入口，不假成功在系统设置修改或保持禁用

不把“界面上看起来成功”当作验收：只有 OS 读回或明确状态才显示开启；屏保/锁屏读不到状态时会显示“未确认”。
