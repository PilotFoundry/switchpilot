# PilotFoundry organization identity

PilotFoundry is the home for small, focused macOS tools, including SwitchPilot.

- GitHub: https://github.com/pilotfoundry
- Tagline: **Small tools, forged with care.**
- Mark: a simplified ship's wheel. The hub, four spokes and rim carry the
  precision/craft; four colored grips (coral, saffron, azure, lilac) represent a
  collection of distinct tools.
- Palette: midnight aubergine / ink base, ivory mark, and four collection
  accents. Intentionally **not** the SwitchPilot forest-green palette; the
  family resemblance is the rounded-square frame, thick rounded forms and soft
  premium finish, not the color.
- App product family: SwitchPilot is `pilotfoundry/switchpilot`; future tools use
  the same frame and a distinct glyph.
