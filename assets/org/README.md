# PilotFoundry organization identity

PilotFoundry is the home for small, focused macOS tools, including SwitchPilot.

- GitHub: https://github.com/pilotfoundry
- Tagline: **Small tools, forged with care.**
- Mark: a simplified ship's helm. Eight ivory grips, a hub, spokes and an outer
  rim make the wheel read correctly at small sizes (a four-grip monochrome
  version turns into a crosshair and was rejected).
- Collection color: four low-contrast aurora pools in the dark field (coral,
  saffron, azure, lilac). The helm itself is single-color ivory, so the mark does
  not become busy; the field carries the "collection of tools" idea.
- Family resemblance to SwitchPilot is **style**, not palette: rounded-square
  frame, thick rounded forms, soft gradient/sheen and premium restraint. The
  organization deliberately does not use SwitchPilot's forest green.
- App product family: SwitchPilot is `pilotfoundry/switchpilot`; future tools use
  the same frame and a distinct glyph.
